AMA PLANNING — DESIGN BLEU SAUGE (OCTOBRE 2026)

Cette version reprend la présentation du modèle Stitch fourni :
• Navigation fixe en bas sur téléphone, icônes SVG intégrées ;
• Cartes plus épurées, raccourcis de navigation, boutons arrondis ;
• Bleu pétrole, vert sauge et sable à la place du noir dominant ;
• Affichage adapté aux écrans de téléphone et d’ordinateur.

INSTALLATION SUR GITHUB PAGES
1. Faites une sauvegarde des fichiers actuellement publiés.
2. Déposez TOUS les fichiers de cette archive à la RACINE de votre dépôt GitHub.
3. Conservez index.html et ama-elegance.css dans le même dossier.
4. GitHub Pages publiera automatiquement index.html.
5. Rechargez l’application (Ctrl+F5 sur ordinateur ; relancez le raccourci sur téléphone).

IMPORTANT
• Il n’y a qu’un index.html dans cette archive (index1.html est omis).
• Le JavaScript métier de l’application et les paramètres Supabase sont inchangés.
• Le nouveau fichier ama-elegance.css contient les styles visuels.
• Les raccourcis visuels utilisent les onglets déjà existants.
• Aucune modification de base de données ni script SQL n’est nécessaire.
• Contrôlez la connexion, le planning, les validations, le partage de missions,
  la facturation et le rôle intervenant après publication.
• Les écrans authentifiés n’ont pas été testés avec les comptes réels.
